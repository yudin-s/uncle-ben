# Contributing

Спасибо за интерес к проекту Uncle Ben.

## Принципы

- Минимальные и понятные PR.
- Изменения должны быть воспроизводимыми локально.
- Безопасность команд важнее «магии» в UX.

## Локальная разработка

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Проверки перед PR:

```bash
make test
```

Или отдельно:

```bash
make unit
```

## Стиль изменений

- Следуйте текущей структуре модулей в `src/uncle_ben`.
- Не смешивайте инфраструктурные и поведенческие изменения в одном PR.
- Добавляйте/обновляйте тесты в `tests/`, если меняется поведение.
- Обновляйте документацию (`README.md`, `docs/*`), если меняется конфигурация или архитектура.

## Pull Request checklist

- [ ] Код проходит `make test`
- [ ] Добавлены или обновлены тесты
- [ ] Обновлена документация
- [ ] Нет секретов в коммите (`.env`, токены)

## Отчёты об ошибках

В issue укажите:

- версию macOS;
- способ запуска (`make run` / `python -m`);
- фрагмент логов из `logs/events.jsonl` (без персональных данных);
- шаги воспроизведения и ожидаемое поведение.

## Лицензирование вкладов

Отправляя вклад, вы соглашаетесь, что он будет распространяться по лицензии GPL-3.0-only (см. `LICENSE`).
