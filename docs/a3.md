# A3 Thinking — Uncle Ben Voice Control for macOS

## 1) Background / Context
Пользователь хочет локальное голосовое управление macOS: wake-word, транскрибация, разделение ролей говорящих, и выполнение системных действий без облачной зависимости.

## 2) Current Condition
- Нет существующего кода.
- Нужен MVP, который можно запустить локально.
- Есть требования к whisper + lightweight LLM + macOS actions.

## 3) Goal / Target Condition
- Фоновый сервис слушает микрофон.
- Определяет речь и транскрибирует текст через whisper.
- Определяет активного говорящего по wake-word `Эй Бэн`.
- Активный говорящий может запускать команды: диктовка, мышь, окна, приложения.
- Команда извлекается lightweight LLM в структурированный JSON.

## 4) Root Cause Analysis (gap)
- Сырый аудиопоток нельзя напрямую отправлять в NLU.
- Без VAD и буферизации много шума и ложных команд.
- Без state-machine нет понятия «кто сейчас управляет».
- Без JSON-контракта между LLM и executor сложно обеспечить предсказуемость.

## 5) Countermeasures
- VAD (webrtcvad) для сегментации речи.
- Whisper (faster-whisper) для локальной транскрибации.
- Controller state: активный speaker + TTL.
- Prompt-контракт: LLM должна вернуть только JSON-действие.
- Action Executor c белым списком команд.

## 6) Implementation Plan
1. Поднять каркас проекта и конфиги.
2. Реализовать аудио пайплайн (capture + VAD + whisper).
3. Добавить wake-word и state-machine контроля.
4. Добавить LLM intent parsing + валидацию JSON.
5. Реализовать macOS actions.
6. Логировать решения и события.

## 7) Follow-up Metrics
- Wake-word precision/recall
- Время от конца фразы до выполнения команды
- Процент корректно распознанных намерений
- Процент безопасно отклонённых команд
