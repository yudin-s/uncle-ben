# Security Policy

## Supported Versions

Проект находится на стадии MVP. Поддерживается только актуальная ветка `main`.

## Reporting a Vulnerability

Пожалуйста, не публикуйте уязвимость в публичном issue до исправления.

Отправьте приватный отчёт с темой `Uncle Ben security report` и включите:

- описание сценария атаки;
- шаги воспроизведения;
- влияние и ожидаемый риск;
- минимальный proof-of-concept (если применимо).

Если контактный email владельца репозитория не указан, откройте issue без технических деталей и запросите приватный канал связи.

## Security Notes for Users

- Приложение имеет доступ к микрофону и, при выдаче разрешений, к управлению вводом macOS.
- Не запускайте проект с недоверенными `.env` файлами.
- Проверяйте `RISKY_ACTIONS` и слова подтверждения перед использованием.
- Не храните чувствительные данные в `logs/events.jsonl`.
